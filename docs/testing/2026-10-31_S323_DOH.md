## Implemented contract

An upstream is configured as `upstream <index> doh <https-url> [connection IP|-]`.
The URL carries host (name, IPv4 or bracketed IPv6), optional port (default 443)
and an origin-form path with optional query. No userinfo, fragment, other scheme,
or path above 512 bytes is accepted. Without a connection IP, or with `-`, a
host name is resolved only through the original network's existing DNS, exactly as
a DoT name is; a literal IP host connects to itself. The VPP-saved endpoint keeps
its existing layout: transport 4, port, optional connection address, and an
`identity` field holding `host NUL path NUL` (255 bytes in total). Only the host
part is the TLS service identity, SNI and observation `service_identity`; the path
never reaches the TLS layer or the record. Route validation lives in
[`product_dns_route.h`](../../src/product/vpp/product_dns_route.h).

The exchange is one HTTP/1.1 POST per connection (`Content-Type` and `Accept`
`application/dns-message`, `Connection: close`) over the S322 TLS profile with
ALPN offering only `http/1.1`. [`product_dns_http.c`](../../src/product/vpp/product_dns_http.c)
frames the response incrementally and bounds it: 8 KiB of headers and 64 fields,
DNS-sized body, `Content-Length`, chunked or connection-delimited bodies. A
connection-delimited body is complete only after TLS `close_notify`; a bare TCP
end is a failure. Each of these is a distinct, observable failure and a failed
attempt for ordered candidates: non-200 status, a 3xx (never followed), missing or
wrong `Content-Type`, `Content-Encoding` or `Transfer-Encoding` other than
identity/chunked (no compression), repeated or malformed `Age`, folded or
malformed lines, header/body limits, trailing bytes, and early close. A server
with no mutual ALPN protocol (HTTP/2-only) is reported as `ALPN_REFUSED` and is
not downgraded; a server that omits ALPN is tried as HTTP/1.1 and recorded as
`ALPN_ABSENT`. Exhausted encrypted candidates return the legal local SERVFAIL; no
plaintext, system or public application-DNS candidate is added, and no HTTP proxy
is used.

HTTP `Age` is subtracted from every RR TTL before caching and delivery (floor
zero), and the cache lifetime is reduced by it; local elapsed time is then
deducted as for any cached answer. A TTL that reaches zero is never cached, so an
aged answer is not extended. Messages with no TTL-bearing record are not aged.
Cached DoH data creates no new HTTP or socket claim.

Normal DoH observation is version 11 and keeps the 1032-byte record: named
former-reserved bytes carry `alpn_state`, `http_error` (1–11 are the negated
framing result codes, 12 is ALPN refused), `http_status` and `http_age`. Older
record sizes and the Product C/Rust ABI are unchanged.

## Pixel 6a qualification

One native stage (`android-native-r1`) and one APK (`android-apk-r1`, SHA-256
`a73dfff2…`) built from the committed sources; an unchanged repeat of each had zero
compilations and a byte-identical payload. Ordinary App entry, normal SQLite, clean
stops, an independent finite HTTPS peer on the host (Python/OpenSSL) and a Java
peer on the device for original-network address discovery. The observation v11
fields (`http_error`, `http_status`, `alpn_state`, `http_age`) are the oracle for
every failure and Age case, and the wire captures show no plaintext application DNS.

The 30 cases are: IPv4/IPv6 × UDP/TCP client with configured and discovered hosts,
IP identity, identity failover and all-encrypted-failed SERVFAIL; normal cache and
cache hit; Age 20 (aged remainder cached) and Age 600 above the TTL (not cached,
upstream asked again); chunked, partially written and close-delimited bodies; each
of 404, 301 not followed, wrong `Content-Type`, early close and ALPN refusal served
by the backup; all-HTTP-failed SERVFAIL; and Stop during a gated handshake.

Findings that changed test code only (Product sources were not touched after the
artifact build): the host peer must offer ALPN `http/1.1`; the wire witness default
of 1024 packets ended long matrices early and is 8192; and the designed 5–30 s
candidate cooldown means a case that must start on the primary has to wait it out
after a failure case, including the handshake-Stop case that follows
all-HTTP-failed. After the runs the original APK and all 4861 private-data members
were restored at generation 2956 in both fields
(`original-restoration-r4`), with no runtime process, NFQUEUE or Product hook left.

## Qualification boundaries

Not covered: Root N3 and VPN N3 matrices, cellular or Wi-Fi handover during an
exchange, a real public DoH service, and a truly HTTP/2-only server. HTTP/2-only is
represented by a server that returns the `no_application_protocol` alert, which the
Product reports as `ALPN_REFUSED` and never downgrades. The fixture CA and leaf are
short-lived offline test certificates; regenerate them before any rerun. The saved
configuration readback shows the host part of the identity, not the request path;
the path is verified at the peer from the actual request line. Product-owned DoH
availability is established for the exercised Root and VPN N1 entries, and external
encrypted-DNS blocking rules may be recommended by the Product only on that basis;
they remain the user's choice and are not created or enabled by this ticket. DoQ,
HTTP/2 and HTTP/3 transport, DNSSEC validation and cross-App association
enforcement remain outside this ticket.
