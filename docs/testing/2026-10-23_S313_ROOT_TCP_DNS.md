# S313: Root original-path TCP DNS

S313 adds bounded, owner-local TCP DNS framing to the Root/NFQUEUE path. It
reuses the shared DNS codec, request correlation, whole-rule policy and normal
observation service. Allowed queries and answers retain their original bytes
and destination. A policy rejection drops the original packet and can affect
other messages sharing that packet or connection. This implements the Root TCP
slice of the [approved DNS specification](../product/APPLICATION_DNS_SPEC.md).
VPN TCP remains disabled here and belongs to S314. Proxy/replacement, cache,
association consumption and cross-App/profile visibility remain later work.

## Processing and bounds

Each FlowEntry binds its TCP state to the actual generation and incarnation.
SYN establishes the byte origin independently in each direction. Bounded copies
handle split length prefixes/bodies, coalesced frames, pipelines, duplicates,
out-of-order bytes and streams longer than one 65,535-byte message. Completed
history can slide out of the finite window. Midstream starts, gaps, copy gaps,
conflicting overlap, expired incomplete frames and capacity remain explicit
unavailable coverage; they never manufacture a domain or caller.

The original packet completes synchronously through PRE, at most one necessary
Flow advancement, then POST with the actual current facts. No packet waits for
recognition and no VPP buffer, packet pointer, policy snapshot or Frame is
retained. Complete messages use current policy; retained rejection facts are
re-evaluated rather than caching an old permission. Connected QName/CNAME
candidates retain full per-name expressions, Rank, AND/OR/NOT availability,
Observe and independent generic rules. QName does not supply SNI, and transport
predicates keep the actual packet direction, protocol and ports. Original
Unknown caller stays Unknown. Reliable DNS caller remains separate from packet
UID and response correlation includes the complete existing request context.

There are at most 32 TCP flows per owner, with a 192KiB allocation ceiling per
flow, a 65,535-byte message ceiling, the existing 1,024 request slots/ten-second
request window, 32 aliases and a 512KiB synchronous codec ceiling. Static
assertions bound the aggregate DNS work to the existing 8MiB owner budget.
Existing owner timers expire incomplete state; FlowEnd and stop release it.
Retirement during a synchronous parser borrow is deferred until that call ends
and cannot donate bytes to a replacement incarnation. Stop reports zero DNS
requests, codec bytes, operations, active TCP flows and owned TCP bytes for
every owner, followed by the complete native-zero tuple and process absence.

Normal DNS ABI v7 is 592 bytes. Per-direction message ordinal, TCP sequence and
continuation plus actual packet direction prevent coalesced messages sharing
one packet token from overwriting each other. Rust retains UDP v5/v6 decoding
and stored-key compatibility. Query policy and current response policy remain
separate. Coverage/error records do not invent missing header fields.
`delivery=0` records policy; App, independent peer and wire witnesses prove
actual delivery or timeout.
