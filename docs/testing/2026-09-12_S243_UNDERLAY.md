# S243 — real underlay replacement and lifecycle evidence

This records the Product implementation of the UDP semantics accepted on
2026-09-12 in ADR-0007. An invalid transport closes its old PCB, socket and
unsent queue. After cleanup, a later permitted datagram may create a new
transport for the same five-tuple and application socket. VPP FlowEntry
identity/lifetime remains independent. There is no proactive migration,
queue replay, unprotected fallback or remote-session continuity promise.

## Real network loss, replacement and unchanged application sockets

`build-output/s243-20260912/pixel-underlay-l` independently passes in one
unchanged runtime generation, **1290**:

- Eight established app TCP/UDP IPv4/IPv6 flows cover both canonical owners.
- The collector disables real Wi-Fi, records Android's old Network loss and
  both owner notifications, and checks all eight old transports close.
  Android aborts the four TCP sockets before its `onLost` callback on this
  device; their actual socket failures, PCB destruction and resource cleanup
  are distinguished from the four explicit UDP epoch invalidations.
- The four original application UDP sockets remain open throughout. Their
  datagram outcomes are exactly `echo, timeout, timeout, echo`: initial
  Wi-Fi; no available underlay; restored network with an explicit OUTPUT
  source-port DROP; then explicit removal of that DROP.
- No-underlay authorization returns error 5 with epoch zero and no connect.
  A later real Android Wi-Fi Network has a different Network identity and
  a new binding epoch, **1 → 2**. Old sessions do not reuse their socket.
- The DROP datagrams have `NOT_ATTEMPTED` transport outcome, never enter the
  flow stack/tracker, and never reach the independent peer. Removing the
  rule permits a fresh protected/bound transport for the same app socket.
- Raw `s223` events prove the original UDP FlowEntry slot/incarnation is
  unchanged across the three permitted datagrams, despite the transport
  replacement and policy-cache refresh.
- Eight additional fresh TCP/UDP flows succeed on the new network. Across
  this generation the verifier checks 16 flow identities, 181 captured
  packets, 135 returned packets and 24 created/closed native sockets.
- Stop leaves both owners' sessions, buffers, pbufs, frames, obligations and
  return credits settled; timer, broker and TUN descriptors close. Native
  drain precedes network-subscription closure.

Wi-Fi is restored by normal and failure cleanup. Temporary policy helpers
and their uniquely named state directories are removed; no user lockdown,
SIM configuration, unrelated device or persistent user policy is changed.

**Scope limit:** this Pixel reports `SIM=ABSENT`. The physical acceptance is
Wi-Fi loss → no underlay → a new Wi-Fi Network, not Wi-Fi-to-cellular or
public IPv6 reachability. A remote TCP peer need not receive a final RST over
an already-down link; native socket reclamation is proved independently.

## Implementation and host evidence

The existing `PlatformNetworkSnapshots` subscription now supplies immutable,
generation-owned underlay incarnations. It seeds visible networks before
TUN admission, then updates from platform callbacks. New authorizations use
the current selection; existing still-valid bindings are not relabelled.
Loss/ineligibility retires the old incarnation, and a later incarnation gets
a new epoch even if Android eventually reuses a network identifier.

Each existing owner-local broker channel serializes authorization replies
with a fixed, descriptor-free invalidation message. The Android authorization
lock covers binding selection, protect/bind and reply publication. Writes
are nonblocking; a failed/full control channel triggers the existing bounded
failure lifecycle instead of silently losing invalidation. Only the canonical
worker invokes HEV/lwIP mutation. A bounded session scan gates old input/I/O,
wakes existing cleanup, and does not operate on VPP FlowEntry state.

Real-dependency host evidence:

- 36/36 normal tests pass, including the uninstrumented mutable-state audit.
- 35/35 executable tests pass under UBSan; 35/35 under non-PIE ASan with leak
  detection. The structural mutable-symbol audit is deliberately run on the
  uninstrumented library: initial sanitizer-suite attempts correctly reject
  sanitizer-generated `.data`/`.data.rel.local` metadata, not product state.
  The audit has not been weakened to accept those instrumented archives.
- New dual-stack, two-owner UDP tests verify queued old input/return data is
  discarded, unrelated valid bindings/owners survive, closing tuples reject
  new packets until cleanup, same-tuple replacement has a fresh session ID,
  stale callbacks cannot authorize it, and all sockets/PCBs/pbufs settle.
- New real TCP tests verify invalidation aborts the old stream and subsequent
  old-stream bytes do not create another outbound connection.
- Wire tests exercise ordered reply/invalidation, no-underlay failure,
  malformed/stale envelopes and descriptor reclamation.
- Evidence tampering is rejected in 8 underlay, 7 active-lifecycle and 7
  recovery cases. The existing 8 native VAPI retirement/free mutation tests
  and Android runtime contract also pass.

The earlier failures and fixes in
[`2026-09-12_S243_LIFECYCLE_CHECKPOINT.md`](2026-09-12_S243_LIFECYCLE_CHECKPOINT.md)
