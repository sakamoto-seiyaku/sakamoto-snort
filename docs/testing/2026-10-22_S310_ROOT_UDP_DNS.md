# S310: Root original-path UDP DNS query filtering

Result: `PASS_WITH_EXPLICIT_LIMITS` for SAKAMOTO-310. The controlled Android
Root path evaluates UDP destination-port 53 queries through the shared complete
message inspector and existing full-rule matcher. Allowed queries keep their
original resolver, source port and DNS bytes; blocked queries use the normal
NFQUEUE DROP verdict. Normal persistent observations contain the corresponding
caller reliability, QName, query type, policy identity and decision.

This is the first Root UDP slice of the [approved application DNS specification](../product/APPLICATION_DNS_SPEC.md)
and [ADR-0011](../adr/0011-application-dns-filtering-root-and-vpn.md).
VPN, TCP DNS, DNS replacement/proxying, response/CNAME/TTL association and
subsequent-connection consumption remain later-ticket work. Cross-App/profile
association visibility remains explicitly deferred. No performance claim is made.

## Bounds, tests and review

The complete-message API supports at most 65,535 bytes. Codec memory is capped
at 512 KiB per synchronous owner operation, including allocation headers and
temporary realloc overlap; total configured bound is owner count times that cap.
Every exit destroys codec state. Actual N1/N3 status reports zero live codec bytes
and active operations; normal completion reports zero pending frames, buffers
and obligations. The real metadata CLI check also passed IPv4/IPv6/extensions,
UDP boundary roundtrip, invalid-bound guards and buffer return.

DNS decisions use the existing 480-byte observation envelope and bounded owner
channel. Channel pressure retains existing loss/backpressure counters. The same
SQLite table/transactions retain at most 4,096 recent DNS rows for the existing
24-hour window; normal query/export exposes at most 128 details. Capacity/age/byte
pressure evictions and accepted/rejected/Unknown/incomplete totals are visible.

reserve grows by 4 MiB to 52 MiB. DNS details do not create another database,
writer, queue, durable query operation or independent retention system.
