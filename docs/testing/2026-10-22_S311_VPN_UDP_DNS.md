# S311: VPN original-path UDP DNS query filtering

S311 qualifies shared application DNS query policy on the ordinary Android VPN
TUN/HEV Direct path, at `N=1` and `N=3`, for IPv4 and IPv6 UDP53. Allowed
queries retain their original LAN or public resolver destination and payload;
policy rejection uses the existing packet DROP path. Filtering creates no
proxy or upstream replacement. This is a query-stage slice of
[SAKAMOTO-309](../product/APPLICATION_DNS_SPEC.md), not completion of its TCP,
response/CNAME, replacement, cache or association requirements.

The [independent composite qualification](../../build-output/s311-dns-vpn-udp-20261022/qualification.json)
is `PASS_WITH_EXPLICIT_LIMITS`: 47 checks join the original functional evidence
with two correctly collected normal stops and original-device restoration.
Cold public `.test` queries and the actual Android resolver API query retain
their transport timeouts. No answer delivery is claimed for those queries.

## Shared behavior and caller evidence

`product_packet_graph_dns_prepare` admits original Root/NFQUEUE and VPN TUN
OUTPUT UDP53 packets to the same complete-message inspector and whole-rule
evaluation. Flow-stack return provenance stays on its existing return path.
The validated UDP length survives metadata projection and excludes IP padding.
QName remains a DNS-domain fact and never becomes SNI.

VPN caller reliability comes from the existing asynchronous Android tuple
broker's matching request, runtime generation and admitted flow incarnation.
Only current normal Android App ownership qualifies a later packet. TUN ingress,
a diagnostic UID or an inherited reliability flag cannot qualify it. Known
system/delegate UIDs and special UID ranges remain Unknown. A cold query is
inspected and forwarded without holding it; a later lookup cannot relabel or
replay that completed decision. The existing broker cache, refresh timing,
flow ownership and return/completion contracts are retained.

The existing normal DNS record ABI represents caller reliability, actual socket
UID availability, QName, type/class, original resolver, current snapshot/rule
identity and declared/actual action. Records use the existing owner channel,
Rust decoder and bounded SQLite store. `delivery=0` records a query-stage
decision and does not assert that the App received an answer.
