## Paired compiler/matcher experiment

Each cost row runs 100 compilations and 20,000 queries per repetition. Workloads
are exact distributed keys, dense residual checks, an immediate first winner,
and a distinct-mask miss. Priority, order, stable identity, action and observe
mode vary; signatures include complete result identity/Rank/mode/actions and
NoMatch reason, rather than only ALLOW/DROP. Sources, helper, compiler/version,
flags, executable hashes and raw JSONL results are retained in `cost-host/` and
`cost-arm64/`. ARM64 binaries are pushed, hashed and run through `./dev/adb`, then
removed. They exercise the production compiler/matcher seam, not a POC engine.

Median paired indexed/ordered query ratios (lower is faster):

| Workload | Rules | x86-64 | Pixel ARM64 |
| --- | ---: | ---: | ---: |
| Distributed exact keys | 32 | 0.90 | 0.55 |
| Distributed exact keys | 128 | 0.29 | 0.21 |
| Dense residual checks | 128 | 1.31 | 1.22 |
| Immediate first winner | 128 | 5.28 | 4.82 |
| Distinct-mask miss | 128 | 9.28 | 14.05 |

The 128-rule exact workload measures about **129/146 ns** per indexed call on
x86-64/ARM64, including identical harness result-signature work. The 128-mask miss
measures about **7.06/6.88 microseconds**. Small sets also regress: index hashing
and key construction can cost more than a few ordered residual checks. This is
not a universal speedup. Compilation builds envelopes and index metadata in
addition to T08 placement; the 128-exact case costs **2.27/1.69 times** baseline.
The paired harness uses identical `-O2` settings, separate from the actual VPP
artifact build settings; real graph timings above include packet projection.
CPU frequency, background load and thermal conditions were not controlled for a
release performance/power claim. Raw ranges are retained rather than hidden.

Fixed compiled-view memory is **22,544 → 38,160 bytes**, an extra **15,616 bytes**
per view on both architectures. The two protected banks add **31,232 bytes**.
Current management retains a preflight view while publication builds another,
so the four-view compile/publication overlap adds **62,464 bytes** (152,640 view
bytes total), besides unchanged source, expression scratch and metadata.
The index adds no persistent per-owner allocation or query heap allocation.
The existing stale-generation empty-view local also grows by 15,616 stack bytes
per active caller; fixed thread stacks are not new allocated index caches.
The full rule-management path invokes compilation twice; the microbenchmark
reports one compiler invocation and does not mislabel API/file-I/O time as it.

require their exact snapshot resource record and its bound. Negative testing
also exposed an unchecked Rank on PRE NoMatch; Rank zero is now required.
