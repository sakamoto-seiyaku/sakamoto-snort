# 深度裁决：同一个人，可以直接改变，也可以完整构建

2026-09-30。这是对[CONTROL整线裁决](2026-09-30_CONTROL_DESIGN_VERDICT.md)的整体修订；旧稿保留历史，其永久无第三入口结论由本文替代。不是另拼一条专业线/Debug线，不替 Jobs 本人表态，不以席位或用户疑问直接裁胜负。
基准仍是[产品愿景](../product/NETWORK_CONTROL_PRODUCT_VISION.md)与[统一规则语义](../product/UNIFIED_RULE_ENGINE_SPEC.md)；全部既有能力及授权目标共用下述对象、输入、版本和证据语法。HTML由root维护，本席不另建实现。

## 明确改判与哲学理由

**最终采用三个稳定目的位：网络｜编写｜深入检查。** 目的名称不随任务打开/结束而改变，短状态可变；完整身份、工作题目、版本和会话进入各任务正文。没有另叠一套永久启动按钮/实例坞。
网络延续图→同段贡献→对象/事实→就地改变→实际核对；编写给从零、大量导入、长期跨对象的完整工作；深入检查给健康时也能主动取得的额外真实证据。预演属于候选输入，普通未来窗口属于网络，不因叫检验就移进Debug。
**撤回“＋/搜索及多一次深入足以替长期地址”的旧判断。** 50规则写、组织、分配、试用、提交与修复是完整需求，不因使用者熟练或任务少见降格。＋、全部应用和命名对象搜索仍加速就地工作，不承担持续工作的全部地址。
[1984 Macintosh](https://book.stevejobsarchive.com/#sid-144)把易用与字体/图像的丰富表达连在一起；[2001 Store](https://book.stevejobsarchive.com/#sid-875)把试用、求助、专业软件纳入同一体验；[2010 iPad](https://book.stevejobsarchive.com/#sid-1323)用多层观影体验说明同一工具可以给不同深度价值。材料支撑完整表达与用途相称的形式，不规定三个导航。
同一个人可写一个决定或50个，可先读普通事实再深入。低门槛来自熟悉对象和自然动作，深度来自完整、可续的工作；不按普通/专业角色分流，不把完整树藏成“少用”的例外。
承担代价：三个目的名称持续占空间，用户需学会候选编写与真实深入的区别；回报是任务有固定地址、完整首屏和持续状态。结构要解释它能做的事，不能只因为API已有三个模块就设三入口。

## 公平强反案：固定等价任务壳

C的最强反案是一个连续网络空间，固定三个N/W/D工作位置：空位启动，活跃继续，结束呈结果；每壳同样保留50项、dirty、基线、批配、一次提交、健康Debug和独立证据，1440可关联并排。
**承认它完整，而且与三个目的位在地址几何上基本等价。** C明确启动就在固定位置，结束不移位、D2不增槽；本席撤回“两套指路”和“位置不稳定”的先前反驳，不编它漏功能。
最后选的是具体命名与工艺：常称网络/编写/深入检查，兼容一条与整套、空态与有结果态；实例状态作短副信息，完整范围/版本进正文。深入检查用人的用途表达，不要求先认识后台Debug名称，也不泛指所有检验。
这不是1与3数目获胜；若固定壳采用相同目的/状态/正文关系，就是本裁决的一种等价落实。A/C更偏源实例措辞的整体感仍保留，不能写成全部同意；本席不因用户提出bulk/Debug就自动增入口。

## 一套完整工作语法

| 共用对象/状态 | 含义与各目的位的关系 |
| --- | --- |
| 实际控制身份与目标 | Android资料/共享UID、Linux真实UID始终同一；程序名可帮助观察，不取得独立执行权。改变、Debug、批量与核对都贴实际范围。 |
| 网络观察范围 | 设备/应用/目标、查询或连接、时间/选择各自连续。当前快照、旧事实、生效后核对、普通未来窗口分别标，互相返回不覆盖来源。 |
| 本次编写输入 | 基于明确已保存配置的暂时工作，可含一项或50项；不是第二后端/永久draft/checkpoint。选择、dirty、引用、模式、返回位置在切目的位时保留。 |
| 已保存与正在使用 | 各自权威身份，保存后编译/发布；已存未用不称成功使用，取消未提交输入不能撤销已保存版本。 |
| 资料候选与配置候选 | 资料版本、出处、本地修改和消费者分开；采用加入明确提交/基线变化，不假装同一个数字。 |
| 实际Debug证据 | 独立会话、真实身份/范围、采集覆盖与每记录实际快照归属；本次输入/预计结果不成为已采集依据。 |

动作继续用动词＋对象＋范围：允许天气以后查询此名称；停止Firefox这处组使用；使用这份新资料；提交本次完整输入；结束这次深入检查。不存在一个泛“关闭/保存”承担所有变化。

## 三个首屏与持续工作

| 目的位 | 393的固定首屏与返回 | 1440相关空间 |
| --- | --- | --- |
| 网络 | 时段/覆盖、图与同段应用；无活动也可找全部对象/＋；事实就地改变，完成回原问题 | 图/贡献、列表/事实关联；现在安排短句不充当旧原因。 |
| 编写 | 工作题目、原基线/本次输入/当前saved-active、待定位问题；集合→所选完整编辑→回集合，固定继续未完成工作 | 集合/引用左，定义/真实使用中，候选预演/影响右；可引用实际Debug来源而不混结果。 |
| 深入检查 | 健康时直接选实际身份/目标、额外证据类型、时限/容量；已有会话继续，或明确结束后新开 | 真实过程/条件可用性/结果与所选证据关联；可专注，也可和候选两源并排。 |

编写从零或导入不先选应用；未分配内容是有效状态，使用范围在需要时选择。复杂条件、排序、组引用、批量及配置差异不是资产目录页，而是这次构建的组成。
共享定义编辑只改定义：名字/条件/rank不得取首mode覆盖所有bindings；Firefox observe与Signal enforce分别保留。使用方式冲突定位两来源，子修正留同一候选，不暗中先发布。
一次完整候选保存/编译/发布，不沿原型逐项loop。保存失败留输入；保存未用留权威新版与旧运行版；冲突主动作核对最新内容并继续编写，重新审引用/模式/顺序/影响，不提供盲“覆盖继续”。

## 健康Debug的层级、状态与证据

深入检查是目的工作，不是故障才出现的设置开关，也不是把普通一分钟窗口另启采集。额外规则/阶段证据有自己的有界会话；正常记录、控制与运行方式独立。
首屏只列后端确能提供的证据类型。T28/Flow/SNI当前facts查询与目标逐条件/阶段trace的start/scope/stop/export合同分别标；能力不足表达本次未取得证据，保留目标工作，不拿故障注入冒充用户Debug。
状态统一为未开始、运行中、结束中、已结束/中断、覆盖不足/丢失；“暂停跟随”只暂停阅读滚动，不宣称暂停采集。“结束深入检查”只停额外通道，普通记录/规则继续，切去编写不隐式结束。
默认有界单会话：主动作继续当前会话，另开前明确结束/处理上一临时结果；不静默换UID或无限累积实例。旧引用保留原session/UID/时间/实际版本，不能由D2补D1缺证，也不默建永久诊断档案。
横幅可写当前使用44/会话含42与44；晚到42记录仍属于42。旧完整条件不可取得就标不可取得，保留已知赢家/声明/实际动作；查看现在定义44是另一个对象，不补进42原因。导出原证据及缺失/丢失说明，不要求永存历史条件。
393编写主位始终本次输入，固定会话短条可继续/停止并明确转入实际面；返回恢复所选规则/输入/位置。宽屏“本次输入/预计”与“运行Debug/实际”各有标题、来源和版本，不共用绿色成功。

## 两条跨整线压力旅程

**健康Debug→大量编写→发布→继续实际证据。** 健康深入选UID1000并开始D1→取一条实际事实打开编写→导入50规则、改5增3及共享r4定义但逐binding模式保留→用同一候选预演→完整提交。
若43保存而编译失败，D1仍按实际42；修正发布44后旧行保42，新行按真实44，候选从未冒充使用。停止D1仅结束额外证据，normal继续；回启动问题或原编写，选择/dirty/基线完整保留，缺源不得重写旧条件。
**dirty遇导入/资料采用。** 完整配置导入先进入同一编写任务：明确替换本次输入或取消保留，不能另一路悄悄发布/覆盖。若要替换，先说哪些未提交变化将失去；原配置导入仍是完整替换，不私作合并。
名单候选可作为本次明确配置输入的一项一起审阅；若采用/自动更新/外部保存已改变基线，保留输入并标原预演/影响审阅过期，查权威新saved/active及资料差异后明确续写或放弃。不能只更换版本数字就继续旧候选。
两旅程共用同一身份、命名内容、当前工作和权威配置关系；网络旧事实不被写入新原因，Debug会话不因配置发布变成另一会话，任何一路提交都使相关旧审阅重新核对。

| 29 | 全配置导入/导出/启动修复 | 编写或状态直达，共用候选/基线，无需先有应用。 |

不放松原边界：当前身份批选≠未来整机合同，UINT32_MAX仅可复用；Linux程序线索≠独立policy。地图无country谓词、批量不做身份×IP；DNS目标参数与现SNI合同分开，名单排除/订阅/Debug额外会话不冒称当前API全具备。
保存先于编译、已存与使用分离、旧规则/资料条件缺失诚实、首版checkpoint暂缓继续保持。30项不是已实现验收声明；全体用户快深兼容也不要求每个内部故障注入变成公开Debug证据。
