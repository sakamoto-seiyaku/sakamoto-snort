## 为什么选择这个首页

设计席把设备在一段时间里的事实作为首页对象。短暂的查询、发送和归属未定活动，可能在打开界面时已结束；默认只看此刻连接会把它们推到第二层。时间图承担可触摸的范围选择，紧邻熟悉应用的贡献；两者共同回答“发生了什么、是谁”，不作为两块等权仪表模块。

这不是“图总比应用重要”：图上的范围和下方应用必须使用同一口径，应用一次点击即进入自己的事实。字节图不能代替 DNS 查询、连接结果或记录覆盖；它们有独立、准确的线索。当前连接有固定入口，应用目录/搜索仍可直接找到未活跃应用。

设计席愿承担只想看当前音乐的人越过一段总量/图区域、再选择当前连接的成本。A 品味研究席、B 交互观察席及主评审此前偏好当前应用主位并保留历史线索；他们的最强反对是日常认出对象的速度和所需空间。**这个反对保留，没有被写成所有人达成一致。**

原首页已经明确“最近30分钟”，并有图→时段→贡献的可操作路径。本轮保留这个真实意图，重新约束图、应用、最新快照的关系；不把修整说成首次发明时间观察。

## 从品味落实到具体形态

| 对象或任务 | 本轮明确选择 | 为它放弃什么、承担什么 |
| --- | --- | --- |
| 设备概览 | 可信记录范围 → 同刻度变化图 → 同段应用贡献；选段与贡献直接相连，完整活动、统计、地图和当前连接直接可达。 | 默认当前应用不占最高主位；图和应用的共同时间范围必须始终清楚。安静、DNS-only、缺口也保留同一空间秩序。 |
| 应用联网 | 一个连续事实画布，身份、范围、当前安排短语与管理入口固定；显式选择全部/查询/连接后，主要事实随所选类型变化。 | 舍弃活动/安排两个等权标签，以及情况/事实/安排三张等权大卡。全部条件深入管理，历史来意看当前连接多一步。 |
| 一次旧事实 | 正文始终是当时结果及依据。新决定的保存/生效结果有自己的完成层；后续核对有自己的生效后范围。 | 舍弃旧阻止记录上长期挂新的绿色允许卡。当前管理仍可进入，但不能重新解释过去。 |
| 名单日常 | 匹配名称、精确范围和局部补充/排除成为主体；版本、出处及两类真实用途用短关系说明。 | 来源频率、检查、暂停/停止、采用偏好搬入来源管理；完整消费者、分配、顺序及创建规则搬入使用关系。各多一次深入。 |
| 名单更新 | 手机进入独立审阅：当前/候选 → 精确差异 → 本地修改 → 消费者用途 → 采用。 | 放弃把候选继续接在日常长台账后；增加一次进退和候选、未提交状态、来源/消费者往返位置的维护。 |
| 全设备安排 | 概览、活动、联网安排各兑现一个工作；安排首层认控制对象，专业规则/组/名单仍有固定维护空间。 | 资产目录不再争普通首屏；查完整共享关系多一步。“安排”是已有规则/组/分配的视图，不新增实体或规则模型。 |
| 主动观察与诊断 | 普通未来一分钟是持续记录中的活动窗口；独立诊断必须提供可说明的额外判断/阶段证据。 | 舍弃只有计时器和报告包装的重复流程。诊断的真实证据深度仍需定义，不假装已有能力。 |

名单本身是匹配资料，不能被画成阻止开关。尚未使用的名单仍有完整内容，创建资料不自动启用规则。复杂安排也不能压成一句“允许全部”或“查询全拦”；已知条件可用短语，混合条件用诚实索引和完整管理入口。

## 最后一轮实屏反驳改变了什么

A 品味研究席与 B 交互观察席各实际看了四幅手机参考，并向设计席发送至多两项强质询；设计席真实答复后，各作一次有界收束。以下是消息交流的摘要，不是模拟对话。

| 最强反驳 | 设计席接受的修正或拒绝理由 |
| --- | --- |
| 图优先仍在混合历史总量与“正在接收”，为何不先让人认应用？ | 保留历史变化主位，但应用行改为本段贡献，最新观测与覆盖固定可见，当前连接另有入口。接受混时态反证，拒绝把历史完全退第二层。 |
| 选中查询却用大“发出1.3MB”配两条阻止查询，会暗示未经证明的解释关系。 | 明确撤回这个组合。全部态给准确双口径索引，查询态给查询事实与结果，连接态给相关传输/连接事实；记录按公开次序呈现，不任意精选故事。 |
| 一个时间按钮能否同时承担历史、当前和未来，返回到底到哪里？ | 历史范围、当前快照、决定结果和生效后核对明确区分；固定壳及来源返回保持，后续查询不覆盖原五分钟范围。 |
| 所有字段属于一个资产，是否就都该放在同页？ | 日常名单选择内容主体，真正搬出维护与使用编辑；手机采用更新有独立开始和结束，决定必要的消费者与本地例外仍在审阅正文。 |
| 守护程序已经持续记录，普通未来一分钟为何另设采集页、报告？ | 没有额外证据就留活动窗口；独立诊断以信息增量成立。取消仅链接式工具目录，但固定任务入口须兑现主动发现。 |

只修事实错误仍不能得到品味；本轮进一步要求形态显露用途、相邻内容相互解释、主动作值得占位、深入保持同一对象。这个判断也受事实约束：不能用夸大条件、虚构关系或抹掉缺口换取清爽。
