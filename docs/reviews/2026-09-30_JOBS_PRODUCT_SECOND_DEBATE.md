## 首选：一个掌控回路，三个工作入口

主导航选择 **概览｜活动｜联网安排**。每日打开先认出自己的应用和设备变化，再追到一次事实、决定以后的行为、核对实际结果；高级内容服务这条回路。[1997 的组合可解释性](https://book.stevejobsarchive.com/#speech-apple-1997)与[2007 的功能自发现](https://book.stevejobsarchive.com/#speech-apple-2007)启发此推演，没有规定此导航。

| 入口 | 不可替代的一句话用途 | 固定承接 |
| --- | --- | --- |
| 概览 | 把这段时间的变化和是谁连接起来。 | 设备总体、应用贡献、固定应用目录/搜索；统计、地图为轻入口 |
| 活动 | 让完整实际事实可以持续筛选、追查和返回。 | 应用、目标、类型、结果、时间；一次事实与当时依据 |
| 联网安排 | 让以后怎样处理及共享使用关系可以明确维护。 | 按对象查看、准确使用关系、专业规则/组/名单、完整预演 |

选择独立活动入口，承担持续探索的稳定空间；已知应用由概览固定目录/搜索直达。暂不增加应用主入口。运行状态在所有任务顶部持续可点，设置为固定齿轮，承接偏好、权限与管理环境；不是靠少一个入口证明品味。
点“概览”固定回总体。统计和地图各自保存探索，轻入口再次打开恢复相应选择并清楚标范围；子返回沿来源恢复原时段、对象、筛选和位置。代价是维护多份查询状态，收益是每个主入口的名称兑现位置。

## 一套对象句，保持不同对象与时间

统一的是“谁／哪项内容／什么活动／何时改变”的动作句；专业规则、组、名单保留名称，不给它们统称开关。普通层显示熟悉应用，扩大到共享控制身份时才显露实际成员与范围。

| 面向用户的句子 | 改变的对象与边界 |
| --- | --- |
| 允许天气以后查询 metrics.example.net，仅此名称 | 当前控制身份下的明确查询规则；不自动允许连接、其他应用或子域名 |
| Firefox 不再使用日常联网，Signal 继续使用 | 调整一项共享分配的使用对象；组保留，Firefox 的其他安排继续判断 |
| 暂停检查跟踪域名的新资料；目前资料仍在使用 | 更新维护状态；不停止名单匹配或规则 |
| 使用这份新资料 | 候选进入保存/生效过程；结果分别说明资料保存与实际使用 |
| 查看这个名称的后续查询 | 真实、同对象/目标/通道、生效后的核对范围；无新记录仍待验证 |

保存是一个结果阶段，不能暗示生效；允许是规则处理，不能保证应用功能恢复。仅观察明确命中后的实际允许及来源。整条共享关系解除必须列全部受影响对象；局部移除通过调整使用对象完成，默认允许不是可删除资产。

## 深层维护的一次完整转场

1. 概览选 09:21–09:26 → 天气 → 一次被阻止名称查询；保留天气、目标、查询类型、该记录时间及来源选段。
2. 选择“允许天气以后查询这个名称” → 本次决定的结果层分别说明保存/使用与范围 → 查看后续查询。后续另建生效后查询范围，返回原任务仍是 09:21–09:26。
3. 完成后回旧事实，正文固定当时结果与依据；不留当前允许句卡。独立“查看现在的联网安排”进入当前管理。代价是少了同屏比较，收益是形式把过去与现在分开。
4. 在当前管理选择“查看全设备共享安排”，明确扩大范围 → 日常联网，共同用于 Firefox、Signal → 调整使用的应用 → 仅移除 Firefox。结果回顾 Firefox 不再通过本关系使用、Signal 保留、其他安排继续判断。
5. 从组内规则打开跟踪域名，标题换成共享名单并列全部消费者 → 来源维护 → 暂停检查。资料与使用继续保留，返回组/原应用的路径保留；不把共享详情仍叫“天气的设置”。
6. 返回最初那次查询，仍显示当时事实。当前名单只解释现在内容/用途；缺少历史匹配证据就不能补证明，不为本轮新增历史名单归档。

准确使用关系先复用既有三项分配，不新建有效策略实体；按应用看完整有效顺序是其投影。修改同一共享规则先列其他使用者；要只改天气则创建/调整其明确局部规则，不能偷偷改共享资产。

## 主动探索、新决定与运行信任如何出现

**主动探索：**地图和统计在概览固定可达；完整活动有自己的位置。普通“看未来1分钟”在活动页锁定未来窗口，显示对象、记录状态、覆盖与结束，留在真实事实工作区；不另造采集启动页或报告包装，不改变守护程序与规则方式。
**新决定：**事实内做短局部决定，完整条件进入专业编辑；联网安排页固定“预演一次活动”，无既有规则也可用。查询/连接明确选型并使用各自事实；当前使用、已保存未使用、本次待提交方案明确分开，无方案先创建暂时输入，预计结果不证明执行。
**真实诊断：**只有普通记录没有的明确判断/运行阶段证据，才成立为有范围、时限、停止与报告的独立任务。启动前说明新增采集内容；应用“更多检查”和运行问题均可达，正常也能主动进入。未具备额外证据，就不能用计时器冒充诊断。
**运行信任：**首层呈现当前是否控制、是否记录、最新与覆盖、未生效的实际影响和一个下一步；正常时暂停与进一步状态可达。Root/VPN、权限、后台、DNS 环境和导入配置进相应次层。恢复步骤由运行状态承接，不另给正常/待授权重复首页。
明确取消永久链接式工具目录页，保留完整预演/诊断任务屏与应用直接入口。普通未来观察结束主动作返回真实活动/原范围；有选中事实时，预演它是次动作，不把每份报告送去合成世界。
