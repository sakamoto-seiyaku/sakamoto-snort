# 控制、共享与拦截：全线任务覆盖辩论

2026-09-30，C 整体研究席。只形成设计报告，未改产品或旧报告；以下是首选与异议，不代称 Jobs 本人意见。

**首选：不设独立控制／联网安排主入口。** 概览、活动承接认识设备和调查事实；改变从对象或设备的具名动作开始，长期共享维护拥有可连续工作的任务空间。规则、组、名单、分配是实现所需对象，不因此各得一页或一个主导航。

## 首选与最强替代

设备固定提供全部应用（含无活动、真实控制身份和多选）、新建、预演、配置状态与导入等具名任务；搜索和最近打开可进入命名内容。没有现成访问或规则也能起步，不强迫先选一次命中。

应用／事实内保持当前引用和就地决定；“其他使用处”展开共享关系。打开共同内容后，在同一任务空间连续换命名对象、编辑组成、检查使用者、保留未提交输入；不是每一步退回设备搜索，也不是永久 API 工具目录。

**替代：**独立“以后怎样联网”工作入口，服务整天跨对象创作、集中核对和分配的长期作者；首层仍按工作及实际使用关系组织，不摆三类后台资产等权目录。我承认其会话发现优势，首选承担专业首次进入多一步的成本。若无入口方案只能靠万能“更多”或重复搜索，替代应获胜；这不取消现在的明确选择。

## 共享、停用与全局必须诚实

同一规则来自直绑与组时，解除直绑不等于不再使用。使用关系展示全部来源；去重规则行不放假装覆盖所有来源的关闭开关。observe 仍参与胜者判断且实际允许，不能拿它代替停用。

名称例外默认建立本身份、精确名称／子域、明确通道的普通允许规则，并核对完整顺序；它不改共享资料，也不保证战胜所有限制。

若要求 Firefox 完整退出 r1、保留 G 其他规则且 Signal 原样，首选“分离此处共享内容”：复制必要引用链、重新分配、解除残余直绑，审阅分离后的全序列和仍共享支路后提交完整配置。不新增继承排除或 enabled 语义；代价是分离内容不再随原组相应修改。共享 UID 的两包不能承诺各自执行不同安排。

设备＋可有“给这批对象设置兜底”，首屏列实际身份，标签明确“选择全部当前控制身份”；它不包含未来身份，也不能把不可操作的未知身份偷偷纳入。当前规格／绑定没有证明持续全设备合同，未分配身份值不是通配符。

0 可选身份停在范围选择，可保留未使用规则或看未知事实；不报已建立安排。对长期整机拒绝的目标，本批完成仍不充分；这个差距留给设计裁决，不在产品中加“申请未来合同”的流程，也不谎称目标完成。

## 一个完整跨功能逐屏情境（目标方案）

1. **设备，新建。** 即使没有活动，先导入并保存未使用名单，核对规范化错误、精确／子域及本地排除；创建资料不自动阻止。
2. **意图编辑。** 建查询规则与 SNI 连接规则，明确各自事实；需要时组合网络、地址和协议条件。名称／来源、声明动作及顺序可查，取消保持原配置。
3. **共同使用。** 组纳入两规则及既有组 G，选择两个真实身份及 observe。若其中同源已有 enforce，显示两来源并拒绝；用户明确解除冲突关系后再提交，不自动覆盖。
4. **预演。** 选择本次待提交快照和对应通道的合成事实，看完整顺序、预计动作及不足事实；不是发送请求或真实执行证明。
5. **保存与开始使用。** 保存失败留输入；已保存未使用保留旧运行内容并直达修正；成功明确本批身份。没有 checkpoint 自动回滚。
6. **真实核对。** 从生效时点看同身份／目标／通道后续活动；observe 命中声明阻止却实际允许。无新记录或缺口保持未知，旧阻止记录不改绿。
7. **局部例外。** Firefox 从一项查询建立精确局部允许，核对完整顺序，Signal 不变；若要退出整条共享 r1，则进入明确分离任务，而非假叶子解除。
8. **共同内容更新。** 名单候选审阅精确增删、保留例外及两类消费者；去 Signal 核对后返回同候选。采用结果分别说资料保存／配置使用，暂停检查不停止现有匹配。
9. **整套迁移或删除。** 导入配置逐项审阅规则、顺序、组、分配、名单与作用身份；引用错回原输入。删除／清空先核对使用关系，完成后真实活动保留原调查范围与当时依据。

## 393 与桌面：形态承担精确

393 固定对象／范围，短关系后进入本次任务；复杂条件、共享分离及候选审阅各有清楚开始／退出。决定面板不摊全部组树，名单不拿大来源卡抢内容，提交前作用身份与通道始终可认。

1440 的共同维护左组成、右所选内容与真实使用；选一身份可核对其完整全序列，不能把组内列表当赢家顺序。编辑／预演、差异／消费者可以并排，但保存结果不与旧事实混时态。两端返回保留原查询、位置、未提交输入与候选身份。

| A 品味席：无第三入口是否把专业能力藏深？多来源完整退出／observe 冲突如何实际完成？ | A 选无第三入口及持久共享任务空间；接受局部名称例外与完整退出不同，后者复制必要引用链并解除残余来源。我接受，并反驳不能仍叫“解除一处”：它必须是审阅全序列的完整分离任务。A 补充共享 UID 边界，已纳入。 |
