# 地图与从可视化进入控制：真实对辩

2026-09-30 · B 组研究席。两题分别交 C 组全线库存席、独立设计席，收到真实答复并回应双方反问。只写本报告；未改变原型、规格或 API。以下是本席明确选择及反方案，不代替本轮最终设计裁决。

## 强首选与最强备选

**首选：地图发现空间分布，紧邻真实目标清单承担选择与改变；不设独立普通控制主入口。** 地图从概览、活动固定可达，点击地域就能在原画面选精确目标，不迫使另找规则目录。认出应用/事实后改变，复杂编辑进入具名任务，完成回原对象。
**最强地图备选：目标表先、地图辅图。** C 组认为它更直接辨认控制身份与地址，承担地理探索弱一点的成本；我保留地图首位，因为这页的独有价值是发现去向关系，但拒绝地图独占屏幕或代替目标表。
**最强整体备选：独立“以后管理”工作空间。** 未发生流量的预先安排、未使用内容、多对象比较和长期未提交任务有常驻归宿。这是实质收益；不以目录多、专家不常用或反方人数否定它。

品味理由来自我们对 [1984 Macintosh](https://book.stevejobsarchive.com/#on-the-macintosh)、[2007 Macworld](https://book.stevejobsarchive.com/#speech-macworld-2007) 的推演：熟悉对象与动作对应，表达能力不因简洁而消失。地图上的圆点不能在提交时偷偷变成国家、服务品牌或另一应用；精确清单应与地图相连，而不是读完说明书才找到能力。阅读边界见[一手研究](2026-09-30_JOBS_LOGIC_PRIMARY_RESEARCH.md)。

## 默认图层与三个窗口

默认 **连接去向**：按已观测远端 IP 的国家/地区资料聚合，不按风险着色。标记计量为不同目标 IP，连接记录数与本段收发另列；同一 IP 的多应用/多记录不重复冒充不同服务器。0 B 长连接及有地址的阻止观察仍保留，状态各自说明，不称都已连接。
点地域/标记只改变同范围清单；缩放与地域选中不自动成为规则。精度不足时用地区聚合，不画街道精确点、设备到全球的动画传输线或外国风险红区。地理资料来源/更新时间可查；用当前资料补标旧记录明确为当前标注，阅读中的投影不静默换版。

## 没有被好看地图删掉的事实

| 情况 | 呈现与控制边界 |
| --- | --- |
| 公网 IPv4/IPv6 | 同等查位置、计数和精确选择；地址族保持真实。改一个已见 IPv4 不自动覆盖 IPv6、新地址或整个服务。 |
| 私有、本地链路、回环、共享/保留地址 | 表中分类保留，不放地球点，不推安全性。IPv4 私有段与 IPv6 ULA/link-local 按精确类型区分；演示/文档地址另标示例。 |
| 位置未知、有真实 IP | 留“位置未知”组，可看事实、按身份改精确 IP；没有坐标不等于没有活动。 |
| DNS 阻止/失败、无查询目标 IP | 未入图清单按原名字/对象/时间/结果保留，可进入查询事实及以后查询决定；不能拿 DNS 服务器 IP 当所查名称的去向。 |
| 仅 DNS 返回地址、没有连接证据 | 默认不画成访问；明确的“解析结果”层可展示返回地址，并始终写未证有连接，与默认连接数量/字节分开。 |
| 一个 IP 多名称、多服务或 CDN | 展开真实名称证据及时间，没证据就只给 IP；按 IP 控制影响该身份对此地址的所有用途，不把它叫某服务专属控制。 |

IP 位置不能精确定位个人或街址，也可能缺失；本报告未选择地理提供商。[MaxMind 官方准确性说明](https://support.maxmind.com/knowledge-base/articles/maxmind-geolocation-accuracy)
私有/特殊及文档段依据 [IANA IPv4](https://www.iana.org/assignments/iana-ipv4-special-registry)、[IANA IPv6](https://www.iana.org/assignments/iana-ipv6-special-registry)；例如原型 192.0.2.0/24 是文档段。CDN 共用代理地址及跨地点 anycast 有官方实例，不能从一个 IP 反推出唯一服务或机房。[Cloudflare 官方说明](https://developers.cloudflare.com/fundamentals/concepts/cloudflare-ip-addresses/)

## 范围原样传递，地理选择不替换调查

概览/活动→地图→目标→事实保持时间、观测对象、控制身份、DNS/连接类型、实际结果、精确目标或原搜索语义、协议/网络过滤、选中记录及来源。地理仅加一个可取消的观察筛选；入图子集、未入图数量和完整等价表共同兑现原范围。
默认连接投影遇到 DNS-only 可以是 0，必须保留原查询问题；不能改 app、扩大时间或偷换结果。名称搜索与精确 IP 条件不是同一个字段。目标清单保留关联证据来源，DNS 同时发生或共享地址不自动证明对应连接。
返回恢复原图选择、范围、过滤及位置；后续核对另存决定范围。核对按身份→精确地址/名称条件→通道/网络等条件→生效后时间，不继续用当前国家标签筛选：地理资料更新不能让受控地址从核对中消失。

## 从可视化到完整规则能力

| 动作或能力 | 自然归宿与必要语义 |
| --- | --- |
| 单目标改变、已有快捷/精确安排 | 精确行的“以后怎样访问”先固定身份与 IP 或真实名称/通道；在同对象看现有安排，再次修改重现原范围，解除一处使用不删除共享资产。 |
| 多对象、多目标创建 | 地图选地域后就地精确勾选，冻结【控制身份→IP 集合】配对；默认逐身份形成完整现有规则输入，不生成 app×IP 交叉适用。扩大需明选。 |
| IP/CIDR 与完整条件树 | 具名编辑保留 AND/OR/NOT、地址族、端点/端口、网络/接口、设备/Flow方向、CT、LPI、SNI及缺失事实语义。精确地址不自动扩大前缀；远端双向控制须显式映射出站目的/入站来源，不偷换当前包端点。 |
| 顺序、共享组、直接/继承使用 | 编辑/对象的实际有效顺序；priority/order 决定赢家，组只复用。展开全部来源，规则去重但使用关系保留；共享改变先列消费者。未使用规则/组可从固定搜索及共享管理找到。 |
| enforce/observe、预演 | 真实 observe 保留赢家/声明动作，实际 ALLOW；合成预演选择草稿/已存/使用快照和事实，未知不猜，SNI 前提不因地图放宽。两者不互相冒充。 |
| 保存、编译、失败修复 | 保存失败留输入；已存未用并列新保存/旧使用状态，修正回同编辑任务；成功只承诺已使用，随后用真实活动核对。 |
| 名单、协议目录、统计与目标 | 名单从真实名字事实/共享引用进入完整维护；协议统计可用稳定协议 ID 建条件，不拿品牌猜协议。统计的流量/协议/规则效果保持范围，目标表回完整活动及筛选，不被地图取代。 |
| 专业诊断与未来观察 | 普通未来窗口留活动；额外判断/阶段证据才开有对象/时限/停止的诊断，正常也可主动进入。其证据深度未知，不叫地图一次刷新“诊断”。 |
| 全设备维护、导入导出、无事实创建 | 常驻“＋创建改变/全部控制对象”及固定共享管理，允许从零、多对象、未分配内容。完整配置替换是具名审阅任务，保留编辑返回及冲突核对，不要求先借一条天气活动。 |

Linux 若多程序共享 UID，观测程序名不能制造独立控制身份；先显露共享成员，无法表达精确程序配对时不提交伪承诺。未知应用归属保留原事实；扩大整设备范围是明确决定，不替用户补身份。
统一条件没有 country/ASN 谓词，因此本轮**不承诺持续国家拦截**。批量只能明确选中 N 个 IP 的快照或已有显式地址条件；不同地址、新地址、不同服务不自动覆盖。日后国家控制需独立定义资料、更新与执行合同，不能在地图按钮中暗加模型。

与 C 的全线库存对质另揭示：当前 statistics 只有收发/查询/连接/目标，协议和规则效果入口没有兑现；协议目录可找并创建复杂 observe 规则；批量链路另有入口与保存后按钮问题。前一地图筛选及本文三尺寸观察为本席独立复现，其他项是 C 的具名源码/实走证据，不装成本席逐项验收。
保留的整体反方有具体任务：两对象尚无流量，先建低优先 catch-all DROP 与 SSH允许，比较实际顺序，再完整导入、保留未提交工作与修复。若无第三退化成齿轮迷宫，或跨任务无法稳定辨认草稿/已存未用工作，独立以后管理的净收益成立；此反方不能因多人选无第三就消失。

## 本席裁定与边界

我选择地图+精确清单、对象上改变、无独立普通控制主入口，愿付全局共享维护多一步及多个任务状态维护；C 的表先与独立以后管理仍是强备选。选择依据是空间发现和同对象动作关系，不是页面少、图炫、API多或设计席身份。
本轮覆盖的是整条控制线的功能归宿，未证明所有 API 组合、历史资料、订阅维护合同、未知输入、IPv6 预演、键盘或真实用户任务齐备。DNS/IP 按用户目标继续设计；不得因现实现缺失删价值，也不得把本地前端字段写成正式持久化合同。最终品味裁决仍可推翻上述首选，本报告没有修改 TMP。
