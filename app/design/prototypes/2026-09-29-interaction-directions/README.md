## 三个方向

| 方案 | 主要结构 | 入口参数 |
| --- | --- | --- |
| A：对象与详情 | 左侧功能导航、对象列表、关联规则和访问详情 | `?variant=A&platform=linux` |
| B：活动时间线 | 横向导航、访问时间线、上下文摘要，从结果进入控制 | `?variant=B&platform=linux` |
| C：规则工作台 | 功能栏、规则库、条件和分配工作区 | `?variant=C&platform=linux` |

将 `platform` 改为 `android` 查看手机布局。两端共享含义，Android 使用应用身份，Linux 示例按系统用户 UID 归属；未假设 Linux 已有独立程序级身份。底部评审工具可切换方案、平台、状态及查看当前内存状态。左右键切换方案，在输入框、选择框和编辑对话框内不会截获方向键。

三个方案覆盖相同的基础功能，不以删减功能来制造简洁。方案切换保留当前样例配置；平台切换重新载入相应身份样例。

## 真实语义在原型中的约束

- 解除快捷禁用后，其他规则仍然适用。
- 仅观察属于分配的执行方式，仍参与规则判断；没有用它替代“禁用规则”。解除分配保留规则资产。
- 保存失败保留输入和之前的配置；编译失败保留新保存配置与旧生效配置；启动修复完成后仍需显式启动。
- 历史结果保留当时名称和动作。配置改变后，无法取得的历史条件不使用当前条件冒充。
- 删除仍有引用的规则或列表会给出反馈；组循环和分配模式冲突有校验。
- 没有记录、查询失败、部分覆盖和加载中是不同状态。

评审工具提供正常、修改未生效、保存失败、版本冲突、恢复中、恢复失败、待授权、启动配置错误、暂无记录、加载中、查询失败和暂停场景。它们是可复现的 UI 样例，不触发真实故障。
