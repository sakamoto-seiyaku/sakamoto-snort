## 本轮主要变化

- **应用内直接看连接。** 音乐的两条连接同时呈现去向、状态、近期与累计收发，联网设置紧随其后。查询有单独区域。
- **连接列表能辨认存在状态。** 可看全部、仍保持、已结束或未建立，也可搜索应用、去向及IP；选中行有明确视觉反馈。宽屏原处查看，窄屏进入详情。
- **详情先回答最近在做什么。** 近期观测紧贴状态与目标。累计收发随后以应用与目标之间的方向图表达，建立/首次观察、最后传输、结束或快照时间组成过程。地址与协议展开后可读。
- **持续存在不等于有传输。** 近10秒无数据、连接结束、规则阻止未建立、规则允许但建立超时分别表达。QUIC样例只有首次观察证据，其时长写为至少观察多久；不冒充精确建连时间。
- **时间范围有一致含义。** 连接按已知存续区间与所选时间相交来展示；时段流量按独立收发样例汇总。连接行的累计量仍指整条连接，明确标为累计。长连接不会因最后一笔数据在选区外就消失。
- **决定与证据保持关联。** 规则可能影响现存连接的后续数据；不承诺立即关闭socket。保存、生效和后续观测分别反馈，09:41快照不会被改写。页面返回与浏览器/系统返回都恢复原时段，关联查询的时间与返回标签也准确指向来源。

## 数据和模拟边界

设计继续按目标产品已具备应用身份、DNS/IP/连接事实的前提进行。**全部数据与控制都是本地前端样例，没有修改真实后端。**

`sessionStorage` 存储键为 `sakamoto-connections-v3` 前缀；新的 `scope` 值可开始独立样例。时间以样例时钟09:41为基准。近10秒速率是显式样例观测，累计收发与分时收发样例相互核对，不是持续采样的真实网速。列表中的已结束记录也在该快照里保留其终止事实。

| 直接打开的记录                          | 已知的样例状态                                     |
| --------------------------------------- | -------------------------------------------------- |
| `connection.html?id=s3-c0`              | 音乐正在接收；QUIC仅有首次观察时间，时长为下界     |
| `connection.html?id=s4-c1`              | 天气保持TCP连接，近10秒无传输；有明确建立时间      |
| `connection.html?id=s3-c2`              | 已结束的音乐连接，累计量保留，近期速率不适用       |
| `connection.html?id=s1-c2`              | 被规则阻止，未建立连接                             |
| `connection.html?id=s5-c3&period=today` | 规则允许但建立超时，记录在约125分钟前              |
| `connection.html?id=unattributed-c`     | 应用归属未确定，已知地址与收发可看，应用控制不可用 |

`view=dns-only`、`dns-gap`、`gap`、`quiet`、`no-activity` 保留上一阶段的零字节查询阻止、记录缺口、平静和完整无活动样例。`scenario=save-error` 与 `unapplied` 可查看保存失败和已保存未生效。`period=recent&window=15,20` 表示09:21–09:26，返回时保留。

查看与刷新不会制造流量或新记录。总览画面外的“加入一条样例新活动”才生成标记过的模拟查询/连接，并使用当前模拟配置判断。这仅演示后续记录路径，**不验证真实既有流的规则重新判定、即时断连或真实应用功能恢复**。未知字段保持未知；位置、名称与关联均按给定样例事实表达，不推断传输内容。

## 子代理审视及落实

两位指定的 `gpt-6-sol / xhigh` 子代理实际查看手机、平板与Linux宽窄窗口。它们以熟悉、直觉、精确、克制与完成度提出批评，未改文件。主代理落实的重点：

1. 近期状态和速率原本被累计方向图隔开：把近10秒观测前置，累计图随后呈现。
2. 首次观察时长被写成精确连接时长：按证据区分已建立时长与至少观察时长。
3. 后续页面的系统返回丢失选区：不再先改写来源历史项，两种返回恢复同一原范围。
4. 关联连接的时间标签与返回文案不准确：明确建立/首次记录时间，返回统一指向真实来源。
5. “以后”容易被误解成仅新连接受影响：就地说明现存连接的后续收发也可能按新规则处理，快照保持原样。
