# Sakamoto 交互原型 V3

V3 落实[2026-10-01 体验裁决](../../../../../docs/reviews/2026-10-01_EXPERIENCE_DESIGN_VERDICT.md)：以“我的网络”和“联网规则”两个长期物件组织工作，修改属于所选内容；额外实际记录从具名动作开始。V2 的时间变化→同段贡献、连续应用画布、名单日常内容与独立更新审阅继续保留。

这是可保留、迭代的设计原型，全部数据和提交都是前端样例。没有接入后端、设备或真实流量；原型配置、导出与 Debug 证据不能用于生产。

2026-10-01后续[访问意图辩论](../../../../../docs/reviews/2026-10-01_ACCESS_INTENT_DEBATE.md)已重审默认决定、首次推荐及目标表达。V3保留本轮之前的画面和操作，尚未落实该方向。

用户随后确认当前主Tab为**首页、规则、设置**，其他Tab是否添加后续讨论；见[确认基线](../../../../../docs/product/NETWORK_CONTROL_PRODUCT_VISION.md#2026-10-01-用户确认的交互基线)。本版两主入口保留为阶段原型，尚未落实本次导航确认。


打开 [V3 原型](http://127.0.0.1:4173/v3/index.html)。可用画面外的窗口选择器查看 Android 手机、竖横平板，以及 Linux 桌面、触控竖屏、小窗口。窗口宽度改变构图；Android 应用身份与 Linux 用户控制范围仍各自保持真实含义。

## V2 到 V3 的变化

- 整体入口改为我的网络、联网规则。规则集合先供长期阅读，再从所选项添加、导入和修改；未分配内容也能维护。
- 首页的图与同段应用贡献保持同范围；应用以固定身份、范围、约束短句和实际活动构成连续画布。
- 共享内容有明确名称及全部用途；局部例外、停止一处使用和分离共享内容各自表达真实作用范围。
- 已保存源、实际使用、本次修改、历史事实与额外记录分别保留来源。保存失败保留输入，保存后未使用不改写实际依据。
- “查看当时依据”读取旧事实；“从现在记录实际判断”开启新的有界样例会话，修改与发布期间会话可继续，结束它不停止普通记录。

V2 与之前三目的参考板保留为阶段记录。V3 的[评审与收口](../../../../../docs/reviews/2026-10-01_UI_PROTOTYPE_V3.md)记录三个全新 `gpt-6.1-sol / high` 评审席与设计席的真实答辩、修改和实际复核；[QA收据](QA.md)区分可操作样例、有限表达和未验证范围。

## 建议完整走一遍

1. 首页选一段→天气的查询→09:24记录→当时依据→回该记录→调整以后→核对并保存→核对后续；没有播放新事实时仍无后续证据，完成回原问题。
2. 联网规则查找SSH→读取未分配用途→修改→开始实际记录→回原输入继续→一次核对并提交→继续记录/结束→回同一项已保存内容。
3. 名单候选→全部用途→回同一候选→暂缓或采用；共享组的局部解除、分离与名单修改都有不同范围。
4. 全部应用中的文件工作资料UID1010191与日历/同步共同UID10204可各自操作。共享UID只有一项控制对象；多网络限制保存为该身份的普通条件规则，解除全网快捷限制仍保留它。

默认样例刻意显示已保存43/实际42不一致，帮助检查两份来源的关系。保存/编译响应、自动采用和播放证据都是模拟。通用匹配器、真实预演与Debug采集、生产导入/编译错误定位均未实现；本原型不能作为生产能力验收。
