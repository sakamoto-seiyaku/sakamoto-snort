# 原型浏览器走查

环境：本机 Chromium / Playwright，HTTP 本地预览，所有操作使用隔离的样例会话；没有连接设备或产品后端。

## 页面、布局和资源

- 44 个独立功能页面，在 Android 手机 393 × 852、Android 平板 820 × 1180、Linux 桌面 1440 × 900 和 Linux 窄窗口 640 × 760 下检查，共 176 个组合。
- 检查脚本异常、页面和主内容区横向溢出、空页面、没有目标的可见链接、图片加载。
- 总览 59 个 iframe 全部加载且非空，包含完整页面、宽屏演示和异常状态；未发现缺失资源。
- 手机和平板保持 Android 身份与授权含义；Linux 窄窗保留桌面导航语义。

## 实际操作的任务链

- 通过：访问详情 → 创建规则 → 作用对象/仅观察 → 保存 → 返回原访问，历史结果不变。
- 通过：对象全网与按网络类型的快捷限制 → 保存 → 生效配置。
- 通过：拒绝不支持的导入选项 → 预览合法条目 → 保存列表。
- 通过：创建规则组 → 分配到对象 → 仅观察 → 查看同一分配。
- 通过：保存失败保留草稿和旧版本 → 重试成功。
- 通过：版本冲突保留输入 → 明确读取后重试。
- 通过：已保存/未生效分别投影 → 重试 → 活跃版本更新。
- 通过：导出 JSON → 导入样例 → 替换审阅 → 确认后才更改配置。
- 通过：主题跨页保持 → 清空记录 → 活动为空且配置保留。
- 通过：修改合成事实 → 预计阻止 / 事实不足，运行配置不变。
- 通过：开始限时会话 → 过程事件 → 手动停止 → 报告导出，防火墙继续运行。
- 通过：Root → 选择 VPN → 未授权阻止启动 → 取消/完成授权 → 清理并切换。
- 通过：启动配置错误 → 编辑修复 → 保持未运行 → 显式启动。
- 通过：平板列表选择更新旁栏 → 正确对象详情，仍为 Android。
- 通过：Linux 窄窗口按 UID 控制，网络入口提供有线网络且不冒用移动网络。

## 完成稿评审修正后的专项回归

- 组分配的作用对象在规则编辑器和摘要中一致；手机首个条件在保存栏上方可见。
- 对象及其链接的规则详情展示当前生效版本，不把待生效规则称为当前规则。
- 清空后，首页趋势与平板详情旁栏均为空。
- SSH 不宣称确认无 SNI；从访问进入地区后返回原访问。
- Linux 事件的网络事实与可设置的条件一致，页面说明不借用 Android 生命周期。
- 没有操作史的结果页显示未提交状态，总览成功样例明确标记演示。
- 59 个总览 iframe 加载完成、非空且无资源错误。

## 界限

这些检查验证页面和模拟交互，不证明 VPP 规则编译、Android 授权、Linux 生命周期、网络性能或真实诊断采集。尚未进行真实平板设备触控、读屏软件、全键盘操作或全部可访问性验收。外观偏好、组名称持久化、正式数据管理等接入依赖保留在 README 中。
